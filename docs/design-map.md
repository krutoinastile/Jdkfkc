## Панель сигналов (`pine/02_smc_signal_flow.pine`)

| Элемент | Реализация |
| --- | --- |
| Мелкие зелёно-красные столбики у нуля | нормализованная гистограмма MACD (`hist`), прозрачность зависит от ускорения |
| Сиреневая линия | давление внутрибарного потока `pres` (EMA от доли покупок минус доля продаж) |
| Оранжевые и красные треугольники сверху/снизу | `warnUp` / `warnDn` — всплеск объёма на экстремуме давления |
| Зелёные и красные квадраты у нуля | `confUp` / `confDn` — подтверждение направления импульса |
| Символ `⚡` | `plotchar` на всплеске объёма выше `spikeM × среднего` |
| Розовая подсветка фона | `bgcolor` при выходе давления за порог `extLvl` |

## Панель осцилляторов (`pine/03_smc_multi_oscillator.pine`)

| Элемент | Реализация |
| --- | --- |
| Синяя, оранжевая и зелёная линии | RSI, Stochastic и CCI, приведённые к шкале −100…+100 |
| Ступенчатая бледная линия | RSI старшего таймфрейма через `request.security` |
| Красная и зелёная заливки по краям | `fill()` между уровнями порогов и границами шкалы |
| Таблица `Перекупленность / Перепроданность` с `100 % / 0 %` | доля осцилляторов за порогом (0 / 33 / 67 / 100 %) |
| Подписи `поток биржевой`, `ТФ скупает` со стрелками | знак внутрибарного давления и знак RSI старшего ТФ |

## Панель потока (`pine/04_smc_exchange_flow.pine`)

| Элемент | Реализация |
| --- | --- |
| Светло-синие и зелёные вертикальные бары | объём бара, окрашенный по знаку дельты, зелёный — всплеск |
| Оранжевая линия | средний объём за `maLen` |
| Режимы «Дельта» и «Кумулятивная дельта» | `delta = buyV − sellV`, накопление с опциональным сбросом каждые N баров |

## Элементы интерфейса TradingView

Не относятся к индикатору и включаются в самом терминале: торговая панель
`ПРОДАТЬ / КУПИТЬ`, таймер до закрытия бара, плашка последней цены на шкале,
подсветка даты под курсором, ручные текстовые пометки (`BAG`) и значок `OTC`.
