# BTC Trading Bot

Telegram-бот для торговли Bitcoin: выдаёт точки входа, ведёт статистику успешных и неуспешных сделок.

## Стратегия

**Trend + EMA Crossover + RSI + ATR**

| Компонент | Параметр |
|-----------|----------|
| Тренд | Цена vs EMA55 |
| Вход | Пересечение EMA9 / EMA21 по тренду |
| Фильтр | RSI(14) — без перекупленности/перепроданности |
| Stop-Loss | 1.5 × ATR(14) |
| Take-Profit | 2.5 × ATR(14) (~1.67 R:R) |
| Таймфрейм | 1H (настраивается) |

### LONG
- Цена выше EMA55 (восходящий тренд)
- EMA9 пересекает EMA21 снизу вверх
- RSI между 35 и 68

### SHORT
- Цена ниже EMA55 (нисходящий тренд)
- EMA9 пересекает EMA21 сверху вниз
- RSI между 32 и 65

Бот каждые 15 минут сканирует рынок. При появлении сигнала — уведомление. Каждые 5 минут проверяет открытые сделки на TP/SL.

## Возможности

- Точки входа LONG / SHORT с ценой, SL, TP
- Статистика: win rate, успешные/неуспешные сделки, средний P&L
- История сделок
- Текущее состояние рынка (цена, RSI, EMA, тренд)
- Push-уведомления о новых сигналах и закрытии сделок

## Быстрый старт

```bash
cp .env.example .env
# Заполните BOT_TOKEN и ADMIN_IDS

pip install -r requirements.txt
python -m app.main
```

Docker:

```bash
docker compose up -d --build
docker compose logs -f
```

## Команды

- `/start` — главное меню
- `/signal` — текущий сигнал
- `/stats` — статистика

## Данные

Цены берутся с **Binance Public API** (BTC/USDT), ключ не нужен.

## ⚠️ Дисклеймер

Бот не гарантирует прибыль. Прошлые результаты не гарантируют будущую доходность. Используйте на свой риск. Это не финансовый совет.
